## 旧工具的适用范围

旧02证明128字节宿主loader记录可读取，正常/paused内容一致。现有 `host/qmp_memory_export.py` 会在读取后无条件cont、异常时不保证输出报告、短于32字节会在unpack抛异常，且1MiB上限只写在契约中。不能原样当真实停顿取证器。

## 本次只做

1. 分离“小记录通道自检”与“事件现场捕获”。现场模式记录原始QMP状态，明确stop并验证所有vCPU已停止后再读；默认保持停止，不自动cont/quit。恢复只能由明确选择触发，并记录其时刻，不能恢复一个原本就paused的现场。
2. 导出以实际静态符号地址和header为依据，先限制header/read长度，验证schema/CPU数/entry大小/总长度且不超过1MiB。按有界块读取实际环，记录分块退出码/长度、完整性和原始二进制；不要逐字节文本扩张成巨量日志。
3. 短读/错地址/错schema/连接异常都输出结构化失败和已取得的原始证据；先检长度再解包。活跃环不要求normal==paused；该比较只适用于原先不可变记录的通道测试。
4. 正常诊断会话中暂停、读、验证，再按明确步骤恢复一次；另测导出失败仍保留报告/状态。loader放置的0x70000000位于RAM不等于内核已保留该页，正式环必须由03提供所有权证明。

## 验收与交付

完整环可冻结后导出、解码，错误路径不自动恢复且保留报告；导出容量/耗时有上限。保存 `capture-contract.json`、原始dump及哈希、停机/恢复时间线、长度/校验结果。此任务不能只复用旧128B静态记录宣布完成。
