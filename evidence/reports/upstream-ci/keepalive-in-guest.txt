# 交付内核的 TCP keep-alive 实测记录

内核: `artifacts/kernel-procfs.bin`（sha256 5261ceb3…，git_commit d3a6ec9，非本次 PR 新编）
guest: 交付 agentos-disk.img（Alpine + busybox，无 python/perl）
探针: `guest/net-keepalive-probe/`（aarch64-musl 静态二进制，HTTP 注入后在 guest 内执行）

## guest 输出

```
=== keepalive probe start ===
kernel: unavailable: No such file or directory (os error 2)
TCP_KEEPIDLE set ok, read back 30
TCP_KEEPINTVL set ok, read back 30
TCP_KEEPCNT set ok, read back 30
=== keepalive probe end ===
```

三个选项均 setsockopt 成功并 getsockopt 回读 30，说明交付内核已实现该功能。
