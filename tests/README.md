# tests/

决赛场景的一键测试入口。

当前仓库还没有可执行脚本；场景、判据与证据要求见 [../docs/finals.md](../docs/finals.md)。
建议按下面顺序补：

1. 30 分钟稳定性；
2. 每 2 分钟加载一次、共 10 次的负载循环；
3. 双标签/窗口与 Alt+Tab；
4. 键盘回显、鼠标点击跳转；
5. JS 交互、CSS 布局；
6. 崩溃、卡死、内存泄漏三类观测。

每个脚本应：

- 从仓库根运行，接受镜像路径与内核路径；
- 输出一段可粘贴的摘要，并把原始数据落到 `evidence/`；
- 失败时返回非零退出码，不能只打印“看起来正常”。
